For agents

Agents and scripts can use the same data as this page. No key needed.

  • /llms.txt: what Route Doctor is and how to call it, in plain text.
  • GET /api/checkup: the dashboard summary. Add ?model=<id>&params=temperature,tools for one model.
  • POST /api/diagnose with {"error": "...", "model": "optional id"}: a cited diagnosis as JSON.
